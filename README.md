 # Tips Prediction Using Machine Learning

## About the Project
This project uses machine learning to predict restaurant tip amounts based on input data.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Flask (if used in the application)

## Project Files
- `app.py` — Web application
- `train.py` — Model training
- `tips.csv` — Dataset
- `tip_model.pkl` — Trained model
- `requirements.txt` — Required Python packages

## How to Run
1. Install Python.
2. Install dependencies using `pip install -r requirements.txt`.
3. Run `python app.py`.
4. Open the local URL shown in the terminal.

## Disclaimer
Predictions are estimates and may not reflect actual customer tipping behavior.
